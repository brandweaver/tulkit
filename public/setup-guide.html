🚀 Tulkit — Windows Setup Guide

Powered by Brandweaver

Step-by-step for non-tech-savvy users. By the end, your Tulkit app will be live on the internet AND any change you make will auto-update your live website within 2 minutes.

⏱️ Total time: ~30 minutes   💰 Cost: Free

🛠️ Phase 1 — Install the tools (one-time setup)

1. Install Node.js (runs the app)

1 Go to https://nodejs.org
2 Click the green "LTS" button (left one) to download
3 Open the downloaded .msi file
4 Click "Next" through all steps (accept all defaults)
5 Click "Install" → wait → "Finish"

2. Install VSCode (where you edit the app)

1 Go to https://code.visualstudio.com
2 Click "Download for Windows"
3 Run the installer
4 Click "Next" through all steps
5 On the "Select Additional Tasks" screen, CHECK "Add 'Open with Code' action"
6 Click "Install" → "Finish"

3. Install GitHub Desktop (uploads your code)

1 Go to https://desktop.github.com
2 Click "Download for Windows"
3 Run the installer
4 Open GitHub Desktop and sign in with your GitHub account
   📌 If you don't have a GitHub account: go to github.com/signup first

📂 Phase 2 — Open Tulkit in VSCode

If you have a .zip file (most likely)

1 Open File Explorer → go to C:\Users\User\Documents\tulkit-download
2 Right-click the tulkit.zip (or tulkit-download.zip) file
3 Choose "Extract All..."
4 Keep the default path → click "Extract"
5 You now have a folder containing your project files

Open the project in VSCode

1 Open VSCode
2 Press Ctrl + K, then Ctrl + O (or click File → Open Folder)
3 Browse to C:\Users\User\Documents\tulkit-download
4 Click on the folder that contains package.json and a src folder
5 Click "Select Folder"
💡 You'll know you're in the right folder if you see files like package.json, README.md, and folders like src and public in the left sidebar.

💻 Phase 3 — Run Tulkit on your computer

1 In VSCode, click Terminal → New Terminal (or press Ctrl + `)
2 A black panel opens at the bottom
3 Type this exactly and press Enter:
npm install
4 Wait 1–2 minutes. Lots of text will scroll by — that's normal.
5 When it stops (you'll see something like added 500 packages), type:
npm run dev
6 You'll see ✓ Ready in 600ms or similar — it's working!
7 Open your browser (Chrome, Edge, etc.)
8 Go to: http://localhost:3000
🎉 You should now see Tulkit running on your computer! Play around with it — create an invoice, download a PDF, test WhatsApp sharing.

🐙 Phase 4 — Upload to GitHub

1 Open GitHub Desktop
2 Make sure you're signed in (top right corner)
3 Click File → Add Local Repository
4 Click "Choose..." next to the path
5 Browse to C:\Users\User\Documents\tulkit-download (the extracted folder)
6 Click "Add Repository"
7 In the "Summary" box (bottom-left), type: Initial commit
8 Click the blue "Commit to main" button
9 Click the blue "Publish repository" button (top right)
10 Keep the name as tulkit
11 UNCHECK "Keep this code private" (so you can use Vercel free — or check it if you want it private)
12 Click "Publish repository"
🎉 Your code is now on GitHub! Go to github.com and you'll see your tulkit repo.

🌐 Phase 5 — Host it LIVE on Vercel (FREE)

1 Go to https://vercel.com
2 Click "Sign Up" (top right)
3 Click "Continue with GitHub" (use your GitHub account)
4 Authorize Vercel when it asks
5 Click "Add New..." → "Project"
6 Find your tulkit repo in the list → click "Import"
7 DON'T change any settings — Vercel auto-detects Next.js
8 Click the big blue "Deploy" button
9 Wait ~2 minutes (you'll see a build log scrolling)
10 When it says "Congratulations!" with confetti → click "Visit"
🎉🎉🎉 Your app is LIVE! You now have a web address like https://tulkit-xxxxx.vercel.app. Share this with your customers — they can use Tulkit from any phone or computer.

✨ Phase 6 — How to make changes (auto-update live!)

This is the magic part. Every time you push to GitHub, Vercel auto-updates your live website within 2 minutes.

To edit locally and see changes instantly:

1 Make sure npm run dev is still running in VSCode's terminal
2 Edit any file in VSCode (e.g. change a colour in src/app/globals.css)
3 Save the file (Ctrl + S)
4 Your browser at localhost:3000 auto-refreshes instantly

To update your LIVE website (the magic moment):

1 Open GitHub Desktop
2 It shows your changes on the left (files you edited)
3 In the "Summary" box, type a short message like: Updated logo colour
4 Click "Commit to main"
5 Click "Push origin" at the top (top right)
6 Wait ~2 minutes
7 Visit your live URL → your changes are there! 🎉
✨ That's it! Edit → Save → Commit → Push → Live. Every single time.

🆘 Common Problems

"npm install" doesn't work

Make sure you installed Node.js (Phase 1 step 1). After installing, restart VSCode and try again.

"localhost:3000" doesn't load

Make sure you ran npm run dev in the VSCode terminal and saw ✓ Ready. Try http://127.0.0.1:3000 instead.

GitHub Desktop won't publish

Make sure you're signed in (top right corner). Try logging out and back in.

Vercel build fails

Open your tulkit folder in VSCode → run npm run lint in terminal → fix any errors → commit and push again → Vercel auto-retries.

Port 3000 already in use

Another program is using port 3000. Close other dev servers, or run npm run dev -- -p 3001 to use port 3001 instead.
